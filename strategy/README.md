# strategy

## What Goes Here
Monthly & quarterly company strategy documents (MM [Bulan] [Tahun] Strategy). One file per period, following the standard format: Kenyataan Saat Ini → Target → Background → Action Plan (pilar + "Berguna buat") → Reinvestment.

## What Does NOT Go Here
Per-division SOPs (go to marketing/, operations/, product/). Raw metrics & financial data go to DB.

## Naming
`YYYY-MM.md` for months (e.g. `2026-06.md`), `YYYY-qN.md` for quarters. Title & tagline live in frontmatter.

## Key Files
- 2026-06.md — Fondasi Data (current)
- 2026-05.md — Scale Up Murid Privat
- 2026-04.md — Fill the Bench
- 2026-q1.md — Attention to Retention
