# Licks in Jazz and Worship

**Jawab OPTIMAL PR MODUL**

## 1: Worship Licks
**Preferensi masing-masing**
Berikut adalah chord dari lagu worship “Amazing Grace”
## do=C
![image13.png](Jawaban Optimal PR Modul Licks_images/image13.png)
**Pada tugas ini Anda akan memainkan lagu dan licks dan jika diperlukan, rekamlah permainan anda **

**Langkah 1 :** **Tulislah kembali chord lagu **tersebut pada selembar kertas
Jawab:
**C.. / Em.. / F.. / C..**
**Am.. / Dm.. / G.. / G..**
**C.. / Em.. / F.. / C..**
**Am.. / Dm.G / C.. / C..**

**Langkah 2 :** Dari licks worship yang sudah anda pelajari di Modul Licks bagian Worship Licks, **pilihlah 1 atau beberapa licks** yang anda sukai
Jawab:
![image14.png](Jawaban Optimal PR Modul Licks_images/image14.png)

**Langkah 3 :** **Mainkan lick **yang anda pilih di pada bagian yang cocok di lagu tersebut, jika diperlukan rekamlah permainan anda.
Jawab:
**C.. / Em.. / F.. / C..**
**Am.. /**** ****Dm.. [Liks masuk] / G.. ****/ G..**
**C.. / Em.. / F.. / C..**
**Am.. / Dm.G / C.. / C..**
